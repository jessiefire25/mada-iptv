# 📺 MadaStream — Global IPTV Player
### Premium Live TV & Streaming App

🌍 Worldwide streaming • Android Phone & TV support • Fast & Reliable • No Bloat

## ✨ Key Features
- 📡 Play M3U playlists & Xtream Codes
- 📺 Optimized for Android TV + remote control
- ⚡ Ultra-fast playback • Low buffering
- 📱 Works on phones, tablets & TV boxes
- 🔖 Favorites, History, Search & EPG
- 🎞️ Lightweight & easy to use

## 📥 Download & Install
1. Go to `apk/` folder → get **`leanback-pro.apk`**
2. Rename it: **`MadaStream-Pro.apk`**
3. Install on your device → Allow "Unknown Sources" if asked

## ⚙️ Quick Setup
1. Open MadaStream
2. Go to **Settings** → Paste your IPTV URL / M3U link
3. Save → Start watching live TV!
